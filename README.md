# AI-Powered Document Question Answering System (RAG)

A Streamlit app that lets you upload PDF documents, ask natural-language questions,
and get answers generated by Google's Gemini model — grounded in the retrieved
document content via FAISS semantic search.

## How it works (RAG pipeline)

1. **Upload** — user uploads one or more PDF files.
2. **Extract** — `PyPDFLoader` pulls text out of each page.
3. **Chunk** — `RecursiveCharacterTextSplitter` splits text into overlapping chunks.
4. **Embed** — each chunk is converted to a vector using Gemini's `gemini-embedding-001` model.
5. **Store** — vectors are stored in a local **FAISS** index.
6. **Query** — user's question is embedded the same way.
7. **Retrieve** — FAISS returns the top-K most similar chunks (semantic search) via a direct
   `similarity_search` call.
8. **Generate** — retrieved chunks + question are combined into a single prompt and sent to
   **Gemini 2.5 Flash**, which generates a grounded answer. (Model names change over time —
   if a model in `app.py` ever gets deprecated, check https://ai.google.dev/gemini-api/docs/models
   for its current replacement and update `CHAT_MODEL` / `EMBEDDING_MODEL` at the top of `app.py`.)
9. **Display** — the answer AND the exact source chunks used are shown to the user.

## Setup

### Option A: One-click (Windows) — recommended

1. Double-click **`setup.bat`**. It will:
   - find a compatible Python version (3.10–3.12) if you have one, or tell you where to get it
   - create an isolated virtual environment in `.\venv`
   - install all dependencies
   - ask you to paste your Gemini API key once and save it to a `.env` file
2. Double-click **`start.bat`** any time after that to launch the app. It opens automatically at
   http://localhost:8501 — close the window to stop it.

If `setup.bat` reports no Python was found, install Python 3.11 from
https://www.python.org/downloads/release/python-3119/ (check **"Add python.exe to PATH"**
during install), then run `setup.bat` again.

### Option B: Manual (any OS)

0. **Use Python 3.10, 3.11, or 3.12.** Very new Python releases (e.g. 3.13/3.14) often don't have
   ready-made installers yet for packages like `numpy`/`faiss-cpu`, which forces pip to compile
   them from source and can fail. If `python --version` shows something newer than 3.12, create
   a virtual environment with an older version instead:
   ```bash
   py -3.11 -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # macOS/Linux
   ```

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Get a free Gemini API key from https://aistudio.google.com/apikey

3. Create a `.env` file in this folder with:
   ```
   GOOGLE_API_KEY=your_key_here
   ```
   (Alternatively, just paste the key into the sidebar when the app runs.)

4. Run the app:
   ```bash
   streamlit run app.py
   ```

5. Open the local URL Streamlit prints (usually http://localhost:8501),
   upload a PDF, click **Process Documents**, and start asking questions.
